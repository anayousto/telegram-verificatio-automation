# Telegram Workflow Automation

Realtime workflow automation backend built with Flask, MongoDB, Telegram Bot API, and Telnyx integrations.

## Features

- Realtime webhook processing
- Event-driven communication flows
- Voice workflow orchestration
- MongoDB integration
- Telegram notification system
- Recording and callback handling
- IVR-style interaction flows

## Tech Stack

- Python
- Flask
- MongoDB
- Telnyx API
- Telegram Bot API

## Architecture

This project demonstrates a realtime communication workflow engine using webhook-driven event processing and asynchronous interaction handling.

## Security

This public version has been sanitized:
- Production credentials removed
- Sensitive business logic removed
- Private infrastructure hidden

## Purpose

This repository is intended as a backend engineering and realtime systems showcase.
